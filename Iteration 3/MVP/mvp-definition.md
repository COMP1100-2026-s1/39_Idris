## MVP Definition

Our Iteration 3 MVP is a responsive UQ Clubs discovery web application that helps students browse, search, filter, view details for, and join university clubs.

### Concrete MVP Features

- Responsive homepage and clubs page for desktop, tablet, and mobile users
- Club browsing page with UQ club cards
- Search functionality for finding clubs by name
- Category filtering by Sports, Faculty, Culture, and Others
- Sorting options for A–Z, most members, and least members
- Clear filters button to reset search, filter, and sorting selections
- Club detail modal with club introduction, activities, location, contact details, and social media links
- Join club interaction to support user engagement
- Improved layout, spacing, typography, and visual hierarchy

### Link to Earlier Iterations

These MVP features were chosen based on earlier iteration feedback and testing, where users needed a clearer way to discover clubs, compare options, and access key club information quickly. The search, filtering, sorting, and clear filters features directly support easier club discovery. The club detail modal improves usability by keeping important club information accessible without forcing users to leave the browsing page. The responsive redesign addresses earlier layout and navigation issues across different screen sizes.
