# UQ Club Discovery Hub – Iteration 3

## Team: 39_Idris

### Project Overview

UQ Club Discovery Hub is a web application designed to help University of Queensland students discover, compare, and evaluate clubs more confidently.

Through interviews conducted across Iterations 1 and 2, we found that students generally have little difficulty discovering clubs. Instead, the main challenge is deciding which club best matches their interests, goals, and expectations.

Our project focuses on reducing this decision uncertainty by providing structured club information, search functionality, filtering tools, and detailed club profiles within a single platform.

---

## Problem Statement

Students currently discover clubs through multiple channels, including:

* UQ Union Clubs Portal
* Market Day
* Social Media
* Friends and Peers
* Student Forums

While these sources help students become aware of clubs, they often provide fragmented, inconsistent, or difficult-to-compare information.

As a result, students frequently experience uncertainty when deciding which club to join.

---

## MVP

The Iteration 3 MVP is a functional React web application that supports:

### Club Discovery

* Browse available clubs
* Search clubs by name
* Filter clubs by category
* Sort clubs by different criteria
* Reset filters and search selections

### Club Evaluation

* View detailed club information
* Compare clubs using structured information
* Access club contact details and social links

### User Engagement

* Join club interaction
* Profile page displaying joined clubs

### User Experience

* Responsive design
* Mobile-friendly interface
* Improved navigation and layout

## Key Learning

A major insight from our interviews, prototype testing, and MVP testing was that club discovery is not the primary problem.

Students already have multiple ways to discover clubs.

The more significant challenge is confidently evaluating and choosing between clubs.

This insight directly influenced our value proposition and MVP feature decisions.

## Running the MVP

Navigate to the React project folder:

```bash
cd uq-clubs
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will run locally and can be accessed through a web browser.
